- The existing Adsterra 300 x 250 banner is included below the journey.

UPDATE patakha.vercel.app
1. Extract patakha-festival-v3.zip.
2. Open the GitHub repository connected to this Vercel project.
3. Choose Add file > Upload files. Upload ALL extracted files into the same
   folder as the existing index.html, replacing matching files.
   Do not upload the ZIP itself or nest the files inside a new folder.
   audio.js and scene.js are new and must be included.
4. Commit the changes to the production branch.
5. Wait for the new Vercel deployment to show Ready, then refresh the game.

Vercel: Framework Other; empty Build Command; Output Directory .
No dependencies, environment variables or build step are needed.

EXISTING PLAYERS
Keep the same production domain to preserve browser-local progress.
Existing four-mission saves are read automatically. A player who unlocked
Grand Finale will start with eight crackers and the Color Explorer mission.
Their best score is preserved. Incognito mode, clearing browser data or
moving domains can reset device-local progress.
